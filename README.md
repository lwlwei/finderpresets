# FinderPresets — release distribution

This repo hosts the `appcast.xml` feed and release DMGs that FinderPresets'
in-app "Check for Updates…" (via [Sparkle](https://sparkle-project.org))
reads from, for the direct-distribution build only — the App Store build
doesn't use this (Apple doesn't allow third-party auto-update in App Store
apps). This repo does not contain the app's source code.
