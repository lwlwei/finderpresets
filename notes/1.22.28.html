Windows and menus

  • A Help menu in the menu bar. While a FinderPresets window is open, the menu bar's Help menu lists Tips & Tricks, What's New and Help.
  • Hide the Dock icon: Settings ▸ General ▸ Menu bar has a new switch. FinderPresets shows a Dock icon only while one of its windows is open; with the switch on it never does. (Its own menu bar, with the Help menu, then doesn't appear either: use the menu bar icon.)

Help
