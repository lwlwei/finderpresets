Side bar

  • Every group can be shown as one row that opens its folders beside the bar: each category, Recent and Open in Finder. The row looks like a folder of the bar, with its own icon, a count and an arrow; a click lists the folders in a panel beside the bar, made of the same rows, so you can open them, drag them out or take them off the bar. One switch (Settings ▸ General ▸ Side Bar, or the bar's “＋” menu) sets all groups at once, and a category's right-click menu sets just that one.
  • Drop a folder on such a category to add it to that category.
  • Reordering shows where a row will land: the line goes below the row you are over when you drag down, above it when you drag up, and a row can be dropped below the last one to send it to the very end. Before, the line was always above, so the end of the list could not be reached.
  • Folders with the same name in those lists show where they are, and the bar no longer waits for Finder when it reads which folders are open.

App groups

  • Add the apps of a Stage Manager stage in one go: App Groups ▸ Add from Stage Manager… lists the stage in use and each stage in the strip; there is also a list of running apps. (Stage Manager cannot be asked which apps a stage holds, so the stages are read from what is drawn on the screen.)
  • Groups can be found and started from the command palette and from Shortcuts and Siri, show which of their apps are running, can be exported and imported, and in Stage Manager mode a note tells you when the first app was not running, since then only it comes back.

Under the hood

  • The App Groups window shows its start mode as two choices that are no longer cut off in English and Japanese, and the screenshot check for each release now includes the new windows.
