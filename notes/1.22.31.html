Side bar

  • A shelf for files. Drag files onto the side bar and they wait on its shelf as links to where they really are, not copies: drag one out and the real file goes, and if the file is moved the link follows it. Hold Option while dropping to keep a copy on the shelf instead. (A file dropped on the bar used to add the folder it was in; folders are still pinned by dropping the folder itself.)
  • Folders dropped on the bar land where you drop them: on the upper or lower half of a row, first or last in a category, or at the end of the bar. A line shows where.
  • Fixed: a folder dropped on a category shown as a menu now goes into it. In the last version this did not work.
  • The list beside the bar has the same right-click menu as the bar's rows, its folders can be reordered by dragging, it can be used with the arrow keys, Return and Esc, and a folder with a repeated name shows where it is.
  • Recent and Open in Finder have their options (show, collapse, hide, as a list or as one row) beside them on the bar, and the “＋” menu keeps only the switch for all groups. A small entry at the bottom of the bar brings back a list that was hidden.
  • Folders open in Finder now follow Finder while the bar is in view, without having to point at the bar.

App groups

  • Each display has its own stages: Add from Stage Manager and New group from a stage list the stages of every display. New: a group can be made from a stage in one click, and its window positions can be saved and put back when it starts (direct download edition, needs the Accessibility permission).
  • A shortcut the system would not accept is flagged in the list, and each app waits until the one before it is in front.

Under the hood

  • The release tests now also check where a dropped folder lands, the shelf and Option copies, and a folder dropped on a category shown as a menu; the screenshot check covers the App Groups window; the test scripts wait for a busy Mac.
