Create Preset Folders

  • Copy a folder's layout, then edit it. In Template from a Folder…, the layout of a folder you pick, the one open in Finder, or the folder(s) selected in Finder (new: Use Finder's Selected Folders) now appears in a text box you can edit freely before saving it as a template: add, delete or rename lines, indent with Tab to nest, start a line with + for a file. Several selected folders each become a folder of the template.
  • A new tip shows how.
