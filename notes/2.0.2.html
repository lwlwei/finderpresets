Side Bar

  • Create a folder that isn't there yet. A dynamic folder whose path doesn't exist yet (today's date folder, say) now has a Create Folder icon beside it, and the same command in its right-click menu.
  • Second-level lists open when the mouse rests on them, with no click: a category shown as a list, Recent, and Open in Finder. Moving to another list switches to it. It never opens during a drag, and can be switched off in Settings ▸ Side Bar.
