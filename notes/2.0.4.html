Opening folders

  • One view for every folder. New in Settings ▸ Opening Presets: Show every folder as None, Icons, List, Columns or Gallery. It applies to folders opened from presets, the side bar, Quick Jump and the command palette; a preset that sets its own view keeps it. The view names now match Finder's, and the default is None (nothing changes).

Menu Bar

  • Tidier command list, in the order you want. Settings ▸ Menu Bar ▸ Choose each command is now aligned, and each command has up and down arrows. The order applies at the top of the menu and under More, and follows your backup.

Side Bar

  • The blue drop line no longer stays behind. After a folder is dropped into the bar, the line that shows where it would go is cleared as soon as the drop is over, even when it ended on another row or below the last one.
