Opening folders

  • Folders you open in Finder yourself can use the default view too. New in Settings ▸ Opening Presets: "Also folders I open in Finder myself". When a Finder window opens, or you go to another folder in it, it is switched to the view chosen under "Show every folder as", once for each folder. Windows that are already open and views you change by hand are left alone, and a preset's own view still wins. It needs the Accessibility permission, and Finder remembers the view for each folder it switches.
