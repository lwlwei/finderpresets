Easier to set up

  • A { } button beside the path field inserts today's date, this year or month, [x], or a name to ask for (a second name becomes “Name 2”). A made-up name that is a capital-letter slip for a built-in one ([Date], [YEAR]) is flagged under its path.
  • mm in a date means the month when the format has no hour or seconds: [date:yyyy-mm-dd] gives 2026-10-28, while the mm in HH.mm is still the minutes.
  • A first preset is one click away: with no preset at all, the editor explains what one is and offers New Preset.
  • The folders list grows with the number of folders instead of scrolling inside a three-row box.
  • Right-click a preset ▸ Open or Duplicate.
  • The name prompt says what is wrong when the folder it searches in is not there (“‘Projects’ is not there — is its disk connected?”), and Return no longer waits for a disk that does not answer.

Steadier

  • No more waiting for a disk that stopped answering when a preset or a side bar row opens, or while a second-level list is used: each look-up gives up after four seconds, says which folder did not answer, and goes on with the rest.
  • Accessibility values from other apps are type-checked (the Open/Save panel watcher, app-group window layout), so an app that answers oddly can no longer take FinderPresets down with it.
