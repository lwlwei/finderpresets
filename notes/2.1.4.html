Easier to use

  • Traditional Chinese reads more naturally: more Taiwan words (尋找, 回應, 載入, 當機, 文字, 介面, 佈局).
  • The Services tip's button opens Manage Presets, where Add to Preset works, instead of the Finder extension settings; the Help page now also explains folders with square brackets.

Steadier

  • A real folder with brackets in its name works in the Side Bar. “[date] Reports” no longer turns into today's date, and “[Client] Project” no longer asks for a name; it opens as the folder it is. Rows added earlier find their folder again; typing a path by hand still makes a template.
