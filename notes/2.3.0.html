Easier to use

  • Presets can be sorted into groups: right-click and choose “Move to Group”, then pick one group at a time from the menu above the list (“All Groups”). Search finds group names too.
  • “Not Opened in 90 Days” in the same menu lists the presets you have stopped using, with the date each was last opened.
  • “Open when a display is connected” opens a preset by itself when a display you pick is plugged in. Window positions are now remembered for each set of connected screens, so the laptop alone and the laptop at a desk keep their own.
  • Folders can open in another app: the small arrow menu beside a folder sends it to Terminal, an editor or any app instead of Finder (direct download version). “Add Files…” puts a document in a preset, and it opens like a double click.
  • “Save Open Finder Windows as Preset…” (under “More” in the menu bar icon’s menu) turns the folders open in Finder right now into a preset, and “Copy Share Link” in the right-click menu sends presets as a link that shows the import preview first.
  • In Quick Jump, → steps into the selected folder and ← steps back out.

Steadier

  • Opening a preset with its shortcut now merges the folders into tabs again. Typing ⌘T while the shortcut’s keys were still held made no tab, so every folder got its own window; the tab is now made from Finder’s own menu. When tabs can’t be made you are told why.
  • “Locate…” suggests a folder of the same name nearby, and you are told once if the menu bar icon can’t be seen (a crowded menu bar or a menu bar manager).
