Easier to use

  • Show the original of a proxy file (direct download version). In Settings ▸ Shortcuts, “Proxy and original folders” pairs a folder of proxies with the folder of originals that has the same structure; “Add Folder Pair” adds as many pairs as you like. Drop a proxy file on the menu bar icon (hold ⌥ to make a preset instead) and Finder opens the original: the file with the same name, whatever its extension, in the same place.
  • A shortcut for it: give “Show Original in Finder” a shortcut under “Other commands”, then select a proxy file in Finder and press it. With nothing selected it uses the folder the window shows.
  • In the side bar an “Originals” row appears once a pair is set: drop a proxy file on it, or click it to look up what is selected in Finder. Files on the shelf have “Show Original” in their right-click menu.
  • When the original isn't there, its folder opens instead, or the nearest folder above it that exists; if the disk of the originals isn't connected you are told so.
