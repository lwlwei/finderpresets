Easier to use

  • Find the original even when the folders are laid out differently (direct download version). For a pair in Settings ▸ Shortcuts ▸ “Proxy and original folders”, tick “Search by name if not in the same place”: when the original isn't at the same place, the whole original folder is searched for a file of that name and every match (up to 20) is shown. Off by default.
  • Names that end differently, and warnings. “Ignore ending” (such as _proxy) lets clip_proxy.mp4 find clip.mov. A pair now says what is wrong with it: a folder that isn't there, the same folder twice, one inside the other, or a proxy folder used twice.
  • More ways to ask for the original: “Show Original in Finder” is in the command palette, in the right-click Services menu, and as a finderpresets://original link.
  • The side bar can dock to Open and Save windows (direct download version). In Settings ▸ Side Bar, with “Pop up the side bar beside Open and Save windows” on, tick “Dock it to the window and follow it”: the bar is as tall as the window, sits beside it, and moves and resizes with it. Off by default, and part of the synced settings.

Steadier

  • Looking up originals is faster and sturdier. Linked folders and different upper/lower case match, a folder of originals is read once however many files you drop, and a disk that doesn't answer is reported after a few seconds instead of leaving the app waiting. If Finder can't be asked what is selected, you are told to check the permission; if only some files had an original, you are told that too.
  • Quieter and easier for VoiceOver: a few timers that run while windows are open now let the Mac batch their wake-ups, and the side bar's “Originals” row can be activated with VoiceOver.
