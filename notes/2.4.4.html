Fixed

  • Folders no longer open as separate windows when the permission is already on. With “Open all folders as tabs in one Finder window” on, FinderPresets could report that it was not allowed to control System Events even though it was, whenever System Events happened not to be running. It now starts it first.
  • The permission checklist looks at System Events too. When folders open as tabs, the Automation item in Settings and the badge on the menu bar icon also warn when FinderPresets is refused control of System Events.
  • A second-level menu opens level with its row. The list of a “Second-level menu” (Recent, Open in Finder, a category) used to open lower the lower in the row you clicked; it now lines up with the row.

Better in “Extra features” (direct download version)

  • “Archive Folders…” copes with folders inside one another. When a preset lists a folder and a folder inside it, only the outer one is archived and the inner one goes along with it, instead of the whole archiving being undone.
  • Dropping files leaves no empty folders behind. A subfolder made for a dropped file that was then skipped or could not be moved is removed again.
