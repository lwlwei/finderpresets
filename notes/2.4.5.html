Fixed

  • No second “which folder?” question after you chose one. When a preset asks for a value and you pick a folder from the list under the field (or press Return on the first one), FinderPresets no longer asks which folder you meant again for the other paths of the preset. The same goes for a folder chosen in the command palette.

New in “Extra features” (direct download version)

  • Open the path on the clipboard from the side bar. “Open the path on the clipboard from the side bar” adds “Open Path from Clipboard” to the side bar's “+” menu: a folder opens in Finder, and for a file its place is shown with the file selected. It also works for files copied in Finder, and the clipboard is read only when you choose it.
