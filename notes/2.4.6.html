New

  • Several names to fill in when creating folders. In “Create Preset Folders” a template can now hold as many names in brackets as you like — [?Client], [x1], [project]. Each time you create, you are asked for each name once, and what you type fills every place that name appears. Different names are asked separately. [x] and the date parts such as [date] are not asked.
  • Folders really called [x]. In a preset's path, [x] still means “any folder here”. Write a folder that is really called [x] in quotes: "[x]". A new button beside the path field switches [x] between the two, and “Insert a part that changes” has a matching entry.

Good to know

  • In a preset's path, [x1], [x2] or any other name in brackets is a name to type: the same name is asked once, different names are asked separately.
